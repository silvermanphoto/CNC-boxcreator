SECTION 2: LOGIC & GENERATION UPDATES
-------------------------------------
[ADD] Combined SVG Layout Mode:
- Requirement: If "Combine SVGs" is selected, generate a single file `Plywood_Layout_Guide_vXX.svg` instead of separate files.
- Canvas: 130" wide x 70" high.
- Features:
  - Draw two 60"x60" Orange Dashed rectangles (representing Sheet 1 and Sheet 2).
  - Sheet 1 Origin: (50mm, 50mm).
  - Sheet 2 Origin: Offset right from Sheet 1.
  - Part Placement:
    - Front Bezel: Sheet 1 (Center).
    - Back Panel: Sheet 2.
    - Rails: Vertical/Horizontal alignment around panels.
  - Glazing Liners: See below.

[REPLACE] Glazing Stops -> Precision Glazing Liners:
- BEFORE: "Rough Cut" rectangles.
- AFTER: "Precision Liners" (CNC milled to exact thickness).
- Logic:
  - `LINER_WIDTH` = (Box Depth + Blind Skin - Rabbet Depth) - (Glass Setback + 0.125" Glass Thickness).
  - `LENGTH`: Calculated to fit snugly inside the box (butt joints) with -0.010" tolerance.
- Global Config: Add `GLASS_THICKNESS` (0.125") and `LINER_FIT_TOLERANCE` (-0.010").
- Layout:
  - Generate 4 parts: 2 Horizontal (Full Width), 2 Vertical (Internal Height).
  - Arrange as a *Vertical Stack* (side-by-side columns).
  - Position: **45 inches** to the right of the main artboard area.
  - Combined Mode Position: At X=105 inches (effectively on/past Sheet 2).

[REFINE] Label Text Logic:
- Requirement: Labels must be readable and inside parts.
- Logic:
  - 1. **Auto-Scale**: Calculate font size based on part width/height (90% coverage).
  - 2. **Centering**: Strictly center text on the part's logical origin.
  - 3. **Z-Order**: "Arrange to Front" - Generate text elements as the *last* item in the SVG structure so they overlap geometry.

[ADD] Unit Conversion Helper:
- Create `convert_string_to_mm(value_str)` to handle inputs like "5'", "4ft", "60 in" for Plywood dimensions.
